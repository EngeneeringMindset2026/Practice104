# Практическая работа №104. Docker

## Цель работы
Познакомиться с Docker, изучить базовые команды Linux и освоить полный цикл работы с контейнерами: от запуска готовых образов до сборки, модификации и публикации собственных.

## Выполненные задания
В ходе работы были выполнены все три задания лабораторной работы:
1.  **Запуск простых контейнеров:** Изучены режимы работы контейнеров (одноразовый, интерактивный, фоновый) на примерах Alpine, Ubuntu и MySQL.
2.  **Сборка и запуск собственного приложения:** Создан `Dockerfile` на основе `nginx`, собраны образы версий 1.0 и 2.0, запущен веб-сервер.
3.  **Модификация работающего сайта:** Изучены `bind mounts`, позволяющие изменять файлы внутри работающего контейнера без его пересборки. Также освоена сборка нового образа с обновлёнными файлами.
4.  **Публикация:** Образы отправлены в публичный реестр Docker Hub.

## Выводы
В результате работы я научился(лась) основным командам Docker для управления контейнерами и образами. Понял(а) разницу между образом и контейнером, освоил(а) методы сборки собственных образов с помощью `Dockerfile` и использование `bind mounts` для разработки. Все задания выполнены успешно.
