Лабораторная работа 104. Docker
## Цель работы
1. Познакомиться с Docker.
2. Изучить базовые команды Linux.
## Ход работы
Была выполнена работа Docker for Beginners, размещённая по ссылке https://training.play-with-docker.com/beginner-linux/.  
Поскольку команданя строка на сайте не работала, было принято решение выполнять работу локально, с помощью инструментов Docker Desktop и VS code.  
Работа выполнялась в терминале PowerShell. В ходе работы были выполнены задания:  
1. Запуск готовых контейнеров (Alpine, Ubuntu, MySQL)  
2. Сборка собственного веб-приложения в двух экземплярах через Dockerfile,под названием "linux_tweet_app" (1.0 и 2.0)  
3. Настройка монтирования (bind mounts) и публикации образов на Docker Hub.
Созданные образы размещены по ссылке: https://hub.docker.com/r/cvb1337/  
4. Сформирован файл (run-lab.ps1), содержащий скрипты для PowerShell, исполненные в ходе выполнения работы.  
## Вывод
Было произведенно знакомство с базовым функционалом Docker: создание и запуск контейнеров, редактирование их во время работы с помощью mount, публикация образов в свой профиль на DockerHub. Неполадки на стороне Play-with-Docker не помешали выполнению работы.
